# 🐽 Хрюнебот

Розширення для Reddit: мітки біля ніків, скарги, нахрюкометр і перевірка історії користувача.
Расширение для Reddit: метки у ников, жалобы, нахрюкометр и проверка истории пользователя.

**Завантажити / скачать:** https://reddit-tagger.reddit-tagger-server.workers.dev/download/

## Що вміє / что умеет

- **Мітки біля ніків** — компактно: 🐽 і 1–2 головні, решта під «+N». «?» — мітка із сумнівом.
- **Картка ніка** (натисніть на мітки): чому такі мітки — людською мовою, звідки кожна (автоперевірка / власник / ваша / спільна),
  головні цифри, ваші мітки, нотатка, оцінка ✔/✖/? і скарга одним натисканням.
- **Спільні мітки й скарги** — базові (зрадойоб, орк, новорег, консерва) враховуються лише від **довірених користувачів**
  («свій» у r/tjournal_refugees, підтвердив нік кодом у коментарі); один акаунт — один голос.
- **🐽 Нахрюкометр** — оцінка за правилами розширення (не факт): скарги людей + автоперевірка історії.
- **Синхронізація між пристроями** за ключем: мітки, нотатки, оцінки й налаштування однакові на компі й телефоні.
  Шифрується на пристрої — сервер зберігає лише зашифроване.
- **Автоперевірка** — де людина пише і як її там зустрічають:
  👹 орк? · 👀 стежу · 🤡 клоун (вимикається) · 🥫 консерва · ❗ новорег · 👎 мінусують · 🥊 спорщик · ✅ свій.
- Автоматика лише підсвічує «придивись», а не виносить вирок. Правила перевіряються вручну на реальних випадках
  (у 1.3.89 правило, що давало хибні «орки», прибрано).

## Приватність / приватность

- Чужі тексти не зберігаються — тільки числа. IP-адреси не зберігаються.
- Ніки для поповнення бази йдуть на сервер лише після вашої згоди («Так» при встановленні).
- Дати активності людей не показуються.
- Дані синхронізації сервер не може прочитати: ключ лишається на ваших пристроях.
- Для довіри сервер зберігає технічний id акаунта (не нік); нік видаляється після перевірки.

## Де працює / где работает

- Firefox (комп’ютер і Android) — підписано Mozilla.
- Chrome, Edge, Brave, Opera, Vivaldi — Windows (zip + `INSTALL.cmd`), macOS (zip + `INSTALL.command`) і Linux (`hryunebot-linux.sh`).
- Яндекс Браузер не підтримується.

## Структура

| Папка | Що там |
|---|---|
| `reddit-tagger/` | розширення (MV3): `content.js` — сторінка reddit і картка ніка, `score.js` — уся логіка балів і міток, `sync.js` — синхронізація, `i18n.js` — переклади UA/RU |
| `firefox/` | маніфест для Firefox |
| `server/` | сервер (Cloudflare Workers + D1): `src/index.js`, `trust.js` (довірені), `sync.js` (синхронізація), `autoqueue.js` (автоперевірка черги), `schema.sql`, сторінка завантаження `public/` |
| `installer/` | установники: Windows (`INSTALL.cmd`), macOS (`mac.command`), Linux (`linux.sh`), шаблон сторінки завантаження |
| `tools/` | тести (`*-check.mjs`) і скрипти масової перевірки через архів ArcticShift |
| `art/` | вихідники значка |
