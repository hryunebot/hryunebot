ХРЮНЕБОТ — встановлення у Windows / установка в Windows

UA
1. Розпакуйте архів: правою кнопкою по zip → «Видобути все».
2. Запустіть INSTALL.cmd (двічі клацніть). Якщо Windows спитає — «Докладніше» → «Усе одно запустити».
3. Виберіть браузер — відкриється сторінка розширень.
4. Увімкніть «Режим розробника» → «Завантажити розпаковане» → виберіть папку, яку покаже скрипт
   (%LOCALAPPDATA%\Hryunebot).
Firefox: просто відкрийте hryunebot-firefox.xpi у Firefox → «Додати» (підписано Mozilla).

Чому не .exe: кілька антивірусів лаялися за евристикою на непідписаний .exe. INSTALL.cmd — звичайний
текстовий файл, відкрийте його блокнотом і побачите все, що він робить: копіює папку і відкриває браузер.

RU
1. Распакуйте архив: правой кнопкой по zip → «Извлечь все».
2. Запустите INSTALL.cmd (двойной щелчок). Если Windows спросит — «Подробнее» → «Выполнить в любом случае».
3. Выберите браузер — откроется страница расширений.
4. Включите «Режим разработчика» → «Загрузить распакованное» → выберите папку, которую покажет скрипт
   (%LOCALAPPDATA%\Hryunebot).
Firefox: просто откройте hryunebot-firefox.xpi в Firefox → «Добавить» (подписано Mozilla).

Почему не .exe: несколько антивирусов ругались по эвристике на неподписанный .exe. INSTALL.cmd — обычный
текстовый файл, откройте его блокнотом и увидите всё, что он делает: копирует папку и открывает браузер.
