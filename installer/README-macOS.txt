ХРЮНЕБОТ — встановлення на Mac / установка на Mac

UA
1. Двічі клацніть по архіву Hryunebot-macOS.zip — з'явиться папка Hryunebot-macOS (зазвичай у «Завантаженнях»).
2. Відкрийте «Термінал» (Cmd+Пробіл → «Термінал») і вставте команду:
     bash ~/Downloads/Hryunebot-macOS/INSTALL.command
   (якщо папка в іншому місці — перетягніть файл INSTALL.command у вікно Терміналу після слова bash)
3. Виберіть браузер — відкриється сторінка розширень.
4. Увімкніть «Режим розробника» → «Завантажити розпаковане» → у вікні вибору Cmd+Shift+G, вставте шлях (Cmd+V) → «Вибрати».
Firefox: можна просто відкрити hryunebot-firefox.xpi у Firefox → «Додати» (підписано Mozilla).
Safari не підтримується.

Чому через Термінал: подвійний клік по скриптах з інтернету macOS блокує («невідомий розробник»), а запуск через bash —
ні. INSTALL.command — звичайний текстовий файл: відкрийте його в TextEdit і побачите все, що він робить.

RU
1. Дважды щёлкните по архиву Hryunebot-macOS.zip — появится папка Hryunebot-macOS (обычно в «Загрузках»).
2. Откройте «Терминал» (Cmd+Пробел → «Терминал») и вставьте команду:
     bash ~/Downloads/Hryunebot-macOS/INSTALL.command
   (если папка в другом месте — перетащите файл INSTALL.command в окно Терминала после слова bash)
3. Выберите браузер — откроется страница расширений.
4. Включите «Режим разработчика» → «Загрузить распакованное» → в окне выбора Cmd+Shift+G, вставьте путь (Cmd+V) → «Выбрать».
Firefox: можно просто открыть hryunebot-firefox.xpi в Firefox → «Добавить» (подписано Mozilla).
Safari не поддерживается.

Почему через Терминал: двойной щелчок по скриптам из интернета macOS блокирует («неизвестный разработчик»), а запуск
через bash — нет. INSTALL.command — обычный текстовый файл: откройте его в TextEdit и увидите всё, что он делает.
